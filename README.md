# nuvio-art

Platform cover art for Nuvio collection folders (Plataformas row and folder headers).

- 2560×1440 JPG, brand gradient background with the platform logo centred.
- Logos are sized so they stay fully visible in Nuvio's folder header, which shows a centre strip of the cover (about 6.7:1 on iPad landscape).

Use the raw URL in Nuvio → Collections → folder → Cover image URL, e.g.
`https://raw.githubusercontent.com/jellothere/nuvio-art/main/platforms/netflix.jpg`

Platform names and logos are trademarks of their respective owners.
